# Technology World

A premium, responsive educational technology experience rebuilt from scratch with a distinctive editorial EdTech startup aesthetic.

## Run locally

No build step is required. Open `index.html`, or run:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000`.

## Included

- Premium responsive visual system with dark/light mode
- Hero illustration built with CSS, SVG connections, and iconography
- 15 technology field cards with category filtering and detail modals
- Interactive network map with connected nodes and contextual side panel
- Animated statistics, timeline, education use cases, comparison tool, resources, and quiz
- Search overlay, mobile navigation, scroll reveal, hover motion, and back-to-top control
- No copyrighted imagery or broken external image dependencies
